# Little Shark: Ocean Quest

An original, family-friendly **horizontal-scrolling underwater arcade game**, featuring a cute yellow shark and octopus enemies. Entirely local HTML5, CSS and JavaScript; no external libraries or assets.

## Worlds and levels

| World | Levels | Theme |
|---|---|---|
| 1 — Coral Cove | 1-1 First Splash, 1-2 Coral Dash, 1-3 Octopus Alley | Bright shallow coral reef |
| 2 — Crystal Caverns | 2-1 Crystal Trail, 2-2 Glitter Grottos, 2-3 The Deep Crossing | Underwater caverns |
| 3 — Midnight Reef | 3-1 Moonlit Waters, 3-2 Tentacle Tunnel, 3-3 Ocean Champion | Deep glowing reef |

## Controls

- Desktop: arrows / WASD to steer, **Space** to dash, **P** to pause.
- Phone: hold the four onscreen arrow keys; tap **Dash** to defeat an octopus on contact during the dash.
- Collect pearls, avoid octopuses and reef pillars, collect shields and bonus stars, and reach the glowing finish gate.
- Three hearts per level, progress unlocks saved in browser storage. Scores and level selection persist on the same browser.
- Fullscreen button works on browsers supporting the Fullscreen API. On iPhone Safari, use **Share → Add to Home Screen** for app-like viewing.

## Hosting on GitHub Pages

1. Create a **public** repository, e.g. `little-shark-ocean-quest`.
2. Upload `index.html`, `game.js`, and `style.css` to the root. You can also upload `README.md`.
3. Go to **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
4. Your game will appear at `https://USERNAME.github.io/little-shark-ocean-quest/` after Pages deploys.
